## 🖤 Sobre Mim

Estou em transição de carreira para tecnologia, construindo minha base em **desenvolvimento web** e **dados** através de estudo prático e muita repetição. Gosto de entender o "porquê" por trás de cada linha de código antes de escrever o "como" — isso me ajuda a fixar conceitos de verdade, não só copiar soluções.

- 🌐 **Desenvolvimento Web:** venho evoluindo de HTML/CSS para JavaScript e React, construindo interfaces funcionais do zero.
- 📊 **Dados:** pratico análise e visualização com Python (Pandas, NumPy, Matplotlib, Seaborn) e já experimentei modelos como RandomForest e processamento de imagem com OpenCV (CV2).
- 🗄️ **Banco de Dados:** estudando SQL para estruturar e consultar dados com mais consistência.
- 🎨 **Design:** uso Figma para prototipar interfaces antes de codar, o que me ajuda a organizar melhor o front-end.
